# 지표 개선

1. 고치기 전에 지표가 어디에 몰렸는지 숫자 3줄(대상·날짜·종류별 상위)
2. 원인 가설 하나를 고르고 규칙 하나만 가장 작게, 설명할 수 있게 바꾼다
3. 바꾼 뒤 같은 명령으로 목표 지표와 지켜야 할 지표를 나란히 다시 잰다
4. 좋아지면 커밋하고, 나빠지면 되돌린 이유를 `docs/DECISIONS.md` 버린 대안 칸에 숫자로 남긴다
5. 제공 데이터의 특정 행에만 맞추는 규칙은 넣지 않는다
6. 처리 시간이면 먼저 재서 가장 오래 걸리는 곳만 고친다
7. 남은 시간이 정한 제출 시각에 닿으면 멈추고, 못 미친 숫자와 원인을 한계로 적는다
