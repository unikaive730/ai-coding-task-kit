# 웹·API 구현

1. 틀은 `.agents/kit/templates/web-python` 또는 `web-node` 에서 복사하고, README 가 정한 스택·경로·응답 필드를 그대로 쓴다
2. 서버는 `0.0.0.0`, 포트는 환경변수 PORT(기본값을 README 에). 8090·8081·2222 는 피한다
3. 입력: 표기만 다른 값은 기준 표기로 받고, 형식 400 · 없는 대상 404 · 업무 규칙 위반 409(과제가 정한 코드가 있으면 그대로)로 나눠 걸린 규칙과 값을 문구에 쓴다
4. 저장: 재시작 뒤에도 남게(SQLite 등), 한 요청의 쓰기는 한 트랜잭션. 같은 대상 동시 수정 두 건의 두 번째 결과를 정한다
5. 화면: 필수 칸·버튼에 id, 빈 상태 · 불러오는 중 · 오류 문구, 저장 뒤 목록이 바로 바뀌는지. 요구에 없는 로그인·큐·캐시는 넣지 않는다
6. 검사는 `python3 verify.py <이름>` 한 명령 안에서 PORT=0 으로 띄워서 한다. 사용자 흐름 하나, 실패 경로 2개, 재시작 뒤 값 확인
7. 사람이 탭 4 에서 띄울 실행 줄을 답의 '다음'에 적는다
