# 새 채팅으로 넘기기

## 넘길 때 (사람이 정한다)
- 압축이 한 번 일어났을 때 · 화면 아래 남은 문맥이 40% 아래일 때
- 같은 오류를 두고 대화가 길어졌을 때 (막힌 것과 시도한 방법을 적고 새로 시작)
- 문서·제출 점검만 남았으면 HANDOFF 없이 `/new` 로 바로 넘겨도 된다 (docs 와 git log 로 충분)

## docs/HANDOFF.md 에 쓸 것 (30줄 안)
- 과제 목표와 성공 기준 (AGREEMENT.md 요약 3줄)
- 끝낸 것 (커밋 해시와 한 줄)
- 지금 하던 일과 다음 한 걸음
- 막힌 것과 시도해 본 방법
- 꼭 지킬 결정과 합의한 해석 (DECISIONS.md · AGREEMENT.md 에서 핵심만)
- 다 쓰면 커밋하고 '넘김 준비 끝'이라고만 답한다

## 새 채팅 첫 요청
"docs/HANDOFF.md 를 읽고 '다음 한 걸음'부터 이어서 진행해. 시작 전에 읽은 내용을 세 줄로 요약해."

- AGENTS.md 는 새 채팅에 자동으로 들어가니 다시 읽게 하지 않는다
- 과제에 원래 AGENTS.md 가 있었고 AGENTS.override.md 가 없으면 첫 요청 맨 앞에 `$kit-rules` 를 붙인다
