# 제공 환경

1. 구성: 에디터 · 터미널 · 브라우저 미리보기 · 오른쪽 메신저(실무자·도우미). 파일 업로드와 `git push` 는 안 된다
2. 과제용 API 키: 환경에 미리 세팅돼 있을 수 있다. 이름만 본다: `env | cut -d= -f1 | grep -iE 'key|token|openai|llm|base_url'`. 값은 출력·파일·커밋·문서 어디에도 쓰지 않는다. README 가 정한 변수 이름이 있으면 그대로 쓴다
3. README 가 모델 호출 기능을 요구하고 과제용 키가 있으면 실제 호출을 시험해도 된다. 테스트는 가짜 응답으로 두고, 실제 호출은 동작 확인에 필요한 만큼만 한다(토큰 사용량이 추적된다). 다른 키·다른 모델 서비스는 연결하지 않는다
4. 키가 없거나 호출이 막히면 멈추지 말고 가짜 응답으로 만들고, 필요한 변수 이름과 미실행 사실을 README 와 VERIFICATION 에 적는다
5. 서버는 `0.0.0.0` 으로 띄우고 터미널에 찍힌 실제 포트를 답에 적는다. 화면 확인은 IDE 미리보기로 한다
6. 메신저는 사람만 쓸 수 있다. 실무자에게 보낼 글은 복사해 보낼 원문으로 답에 적는다
7. 제출은 사람이 화면의 '제출하고 문제풀기' 로 한다. 제출 뒤에는 코드와 문서를 볼 수 없으니, 그 전에 사람이 AI 없이 설명할 수 있게 브리핑을 준다
