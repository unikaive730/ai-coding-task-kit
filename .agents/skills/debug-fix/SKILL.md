# 오류 원인 찾기

1. 오류 원문과 명령을 그대로 한 줄 적는다. 다시 만들 수 있는 가장 짧은 명령을 찾는다
2. 고치기 전에 원인 가설 2개와 각각을 가를 확인 명령을 쓴다
3. 확인으로 원인을 고른 뒤 가장 작게 고친다. 관련 없는 정리는 같이 하지 않는다
4. 처음 실패한 그 명령으로 다시 통과시키고, `docs/VERIFICATION.md` 에 한 줄(명령 · 처음 결과 · 고친 커밋 · 다시 결과)
5. 커밋 본문에 `처음:` · `원인:` · `다시:` 를 실제 있었던 대로 적는다. 확인 질문의 재료가 된다
6. 같은 방법이 두 번 실패하면 접근을 바꾸거나 묻는다. 막힌 것은 `docs/STATUS.md` 에
7. 검사기가 틀린 것 같으면 구현을 맞추지 말고 먼저 어느 쪽이 틀렸는지 README·데이터로 가른다
