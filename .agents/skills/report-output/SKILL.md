# 보고서·결과물

1. 틀은 `.agents/kit/templates/report/report.py` 에서 복사한다
2. 맨 앞에 결론 한 문단: 결과 숫자 · 목표 · 지금 방식과의 차이
3. 숫자는 결과 파일에서 코드로 읽는다. 본문에 손으로 옮겨 적지 않는다
4. 표·그래프마다 무엇의 수인지, 단위, 기준 시점, 만든 명령을 적는다. 그래프는 선 4개까지
5. 못 채운 건과 원인 숫자, 한계, 다음에 검증할 것을 끝에 적는다
6. README 가 정한 제출 파일 이름·경로·형식 그대로 만들고 그 파일은 커밋한다
7. 받는 사람이 README 에 있으면 그 사람이 바로 결정할 수 있는 순서로 쓴다
