# 데이터 정리와 집계

1. `docs/DATA_PROFILE.md` 를 먼저 읽는다. 큰 파일은 일부만 읽고 전체 처리는 스트림으로
2. 코드로 확인해 숫자로 적는다: 열 이름 · 자료형 · 단위 · 날짜 형식과 시간대 · 빈 칸 · 완전 중복 · 키 중복 · 표기 변형(L2=l2, 공백·하이픈) · 범위 밖 값 · 파일 사이 키 매칭률
3. 처리 규칙은 값마다 하나로 정한다(남기기·채우기·빼기). 결과를 바꾸는 해석은 실무자 질문으로, 그 밖은 정해서 `docs/DECISIONS.md` 에
4. 행을 빼거나 고치면 이유와 처리 전후 건수를 DECISIONS 와 `docs/VERIFICATION.md` 에
5. 조인 전후 행 수와 합계를 찍어 늘거나 줄지 않았는지 본다
6. 결과 합계는 입력에서 다른 방법으로 다시 세어 맞춘다. 값을 지어내지 않는다
