# 과제 읽기

1. 안내를 끝까지 읽는다. 언어별 판이 둘이면 둘 다. 제공 파일 목록과 안내가 말하는 파일을 맞춰 본다
2. `docs/AGREEMENT.md` 과제 요구 표에 항목별로 적는다: 요구 원문 · 측정값 · 목표 · 제출 파일·경로·형식 · 시간·길이·건수 상한 · 평가에서 빠지는 조건
3. 금지 문구는 수식어까지 원문 그대로 옮긴다. '반드시·만·제외·이내·이상·초과' 같은 낱말을 놓치지 않는다
4. 권위 순서: 과제 안내 원문 > 실무자 답 > 우리 추정. 자료끼리 어긋나면 건별로 판정하고 근거를 남긴다. 정리본만 보지 말고 막히면 원문을 다시 읽는다
5. 안내가 말하지 않은 것은 금지로 단정하지 않는다. 결과를 바꾸면 실무자에게 묻고, 아니면 정해서 DECISIONS 에 적는다
6. 제출 직전 이 표를 한 줄씩 결과물과 다시 맞춘다
