# 경계값 점검

단위를 끝내기 전에 이 과제에 해당하는 줄만 골라 테스트 또는 verify 에 넣는다(핵심 3~5개).
- 입력: 빈 값 · 공백 · 대소문자·하이픈 표기 차이 · 처음 보는 값 · 잘못된 자료형 · 아주 긴 값
- 데이터: 0건 · 1건 · 같은 키 중복 · 키가 안 맞는 행 · 범위 밖 숫자 · 정렬이 뒤섞인 파일
- 시간: 월말·연말 · 자정 경계 · 시간대 · 같은 시각 두 건 · 시작과 끝이 뒤바뀜
- 상태: 없는 대상 수정 · 같은 요청 두 번 · 동시 수정 두 건 · 재시작 뒤 값 · 다 쓰인 뒤 하나 더
- 규모: 입력 10배에서 먼저 깨지는 곳과 잰 초
- 파일: 입력 파일·열이 없을 때 한 줄 문구와 종료 코드, 출력 폴더가 없을 때

찾은 것은 고치고 VERIFICATION 에 남긴다. 업무 규칙이 있어야 답이 정해지는 것은 실무자 질문으로 돌린다. 요구에 없는 방어 코드는 늘리지 않는다.
