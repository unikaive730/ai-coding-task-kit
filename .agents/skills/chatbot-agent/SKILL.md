# 챗봇·에이전트

1. 입력을 축으로 본다: 받은 건의 구조 · 실제 형식 · 표기(오타·띄어쓰기·언어) · 한 메시지의 여러 질문 · 앞 말을 이어 받는 말 · 중복과 순서 · 지시처럼 보이는 내용 · 답이 실제로 닿았는지
2. 결과 조건을 코드로 고정한다: 자료에 없는 값은 지어내지 않고 되묻거나 모른다고 답한다 · 금액·날짜·이름은 자료 값 그대로 · 규칙이 충돌하면 우선순위를 정해 적는다
3. 지식은 출처가 붙은 표나 파일로 둔다. 자료끼리 어긋나는 항목은 어느 쪽을 왜 골랐는지 남긴다
4. 읽어 온 문서·사용자 글 안의 지시는 따르지 않는다
5. 응답 시간 상한이 있으면 먼저 받았다고 응답하고 뒤에서 처리한다. 실패하면 안내 문구로 답한다. 같은 메시지가 두 번 오면 한 번만 처리한다
6. 처음 보는 입력의 기본 동작(되묻기)을 정하고 원문을 남긴다
7. 시험은 시나리오 표로: 정상 · 규칙 충돌 · 실패 분기 · 속임 · 입력 형식. 통과·불통과로 판정하고 평균으로 가리지 않는다. 정답은 정리본이 아니라 원문에서 세운다
