# 05 나란히 맡기기 · 고칠 파일이 겹치지 않는 단위가 있을 때

터미널 탭을 하나 더 열고 `codex` 를 새로 띄워 붙인다.

```
목표: docs/STATUS.md <번호>번 단위 '<이름>'만 맡아. 고칠 파일: <파일>.
맥락: <입력 형식·합의한 해석>. 제약: 다른 파일·docs/·git 은 건드리지 마.
완료: <명령>이 <기대 결과>를 내면 바꾼 파일과 확인 결과를 3줄로 답해.
```

원래 탭의 codex 에는 이 한 줄을 붙인다.

```
<파일>은 다른 세션이 맡았으니 건드리지 마. 그동안 <검증·문서 단위>를 해.
```
