# 05 탭 2 · 검사 레인 · 계획이 커밋된 뒤, 구현을 기다리는 동안

구현은 탭 1 에서 한 단위씩. 탭 2 에 `codex` 를 새로 띄워 요구 문서만 보고 합격 검사를 만든다(구현과 파일이 안 겹친다). 계획 직후 한 번:

```
$verify-submit 목표: 과제 README·data/ 와 docs/AGREEMENT.md(성공 기준·데이터 해석)·docs/STATUS.md(완료 조건·제출물 형식)만 보고 독립 합격 검사 check_acceptance.py 를 만들어. 구현 코드는 읽지 마.
제약: 표준 라이브러리, 이 파일만 고치고 커밋은 .commit-msg-2·.commit-files-2(이 파일 하나)를 쓰고 bash .agents/kit/commit.sh 2. 성공 지표(대상 건수·지표 숫자·규칙 위반 수)는 결과 파일과 data/ 로 이 파일 안에서 직접 다시 계산해 숫자로 보이고(정답 숫자가 없어도 AGREEMENT 규칙으로 센다), README 의 사용자 흐름 하나(웹이면 로그인 → 실행 → 한 칸 고치기 → 확정 → 다른 역할 조회 → 확정 뒤 거절 → 재시작)를 README 응답 코드대로 차례로 검사해. 아직 없는 결과는 '없음'으로 실패를 보이고, 구현을 봐야만 아는 항목만 '확인 불가'로 따로 세어(실패 아님, 나머지가 다 통과면 종료 0), 서버가 있으면 PORT=0 으로 이 파일 안에서 띄워. 지금은 실패해도 된다.
완료: python3 check_acceptance.py 가 끝까지 돌면 커밋. 답은 검사 항목 5줄.
```

대조는 2~3번(첫 단위 커밋 뒤 · 핵심 기능이 입력부터 출력까지 돈 뒤 · 07 전) 탭 2 에:

```
읽기만: git log --stat 으로 지난 대조 뒤의 커밋(처음이면 docs/STATUS.md 계획 커밋 뒤 전부)을 보고 그 diff 만(파일 전체 말고) docs/AGREEMENT.md 와 대조해 끝난 단위의 틀린 가정·빠진 요구(AGREEMENT 규칙 줄 가운데 코드·DECISIONS 어디에도 처리가 없는 줄 포함)를 구현 쪽에서 3개 이하로 찾고 python3 check_acceptance.py 를 돌려. 파일은 고치지 마. 답은 5줄(찾은 것 · 검사 결과 숫자 · 검사기 자체 고칠 것은 개수만).
```

- 탭 2·5 의 첫 커밋 때 `commit.sh 2`(또는 5) 승인 창이 한 번 뜬다 → p · 탭 2 codex 도 아래 줄이 GPT-6.1-Sol medium 인지 본다
- 찾은 것이 맞아 보이면 그 줄을 탭 1 다음 요청 맨 앞에 붙이고 'DECISIONS 에 사람 한 줄(지적 · 받아들임 · 이유)'도 같이 시킨다. 틀린 지적이면 버린 이유를 같은 꼴로 한 줄(AI 제안을 사람이 거른 기록이 확인 질문 재료). 검사와 구현의 숫자가 다르면 버리거나 고치기 전에 탭 2 에 `읽기만: 구현 결과와 검사 계산이 갈린 항목과 그 원본 행, 갈린 규칙 한 줄. 3줄` 을 한 번 묻고, 그 3줄을 DECISIONS 사람 줄 이유 칸에 넣게 한다(그 차이 자체가 서술형에서 설명할 거리다)
- 검사기 자체 고칠 것이 2개를 넘으면 다음 대조 전에 탭 2 에 `check_acceptance.py 의 검사기 문제만 고치고 커밋. 3줄` 한 번
- 06 의 '다른 계산으로 대조'는 check_acceptance.py 결과로 갈음한다

고칠 파일이 겹치지 않는 구현 단위가 따로 있으면(예: 계산 모듈과 화면) 탭 5 에 codex 를 새로 띄워 맡긴다(탭 2 검사 대화에는 구현을 시키지 않는다).

```
docs/STATUS.md 의 <번호>번 단위·'나란히 계약'과 docs/AGREEMENT.md 성공 기준·docs/DECISIONS.md 만 읽고 그 단위를 만들어. 고칠 파일: <파일>과 그 테스트 파일. 다른 파일·docs/ 는 건드리지 마. 모르는 것은 묻지 말고 (추정)으로 정해 답에 적어.
완료: 테스트 3개 이내(입력은 계약 형식의 작은 예시)가 통과하면 그 두 파일만 커밋(.commit-msg-5·.commit-files-5 를 쓰고 bash .agents/kit/commit.sh 5). 답은 3줄.
```

