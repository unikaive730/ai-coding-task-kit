# 05 나란히 맡기기 · 고칠 파일이 겹치지 않는 단위가 있을 때

터미널 탭을 하나 더 열고 `codex` 를 새로 띄워 붙인다.

```
docs/STATUS.md 의 <번호>번 단위와 '나란히 계약'만 읽고 그 단위를 만들어. 고칠 파일: <파일>. 다른 파일·docs/ 는 건드리지 마. 테스트는 3개 이내, 입력은 계약 형식의 작은 예시로.
완료: STATUS 완료 조건이 통과하면 <파일>만 git add 해서 커밋(index.lock 이면 잠깐 뒤 다시). 답은 3줄.
```

원래 탭의 codex 에는 이 한 줄을 붙인다.

```
<파일>은 다른 대화가 맡았으니 건드리지 마. 그동안 <번호>번 단위를 하고, 커밋은 네 파일만 git add 해서.
```
