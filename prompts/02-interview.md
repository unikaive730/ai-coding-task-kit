# 02 인터뷰 정리 · 실무자 답을 받을 때마다

```
$interview-requirements 목표: 아래 실무자 답을 docs/AGREEMENT.md 에 반영해(누가 말했는지 표시).
제약: 바뀐 칸만 고치고 풀린 차이 줄은 지워. 인터뷰 기록은 질문당 한 줄, 원문은 옮기지 마. 실무자가 정하지 않은 계산 세부는 우리가 정해 DECISIONS 표에 한 줄씩. 코드는 아직. 답에 없는 내용은 (추정).
완료: 성공 기준이 숫자로 다 정해졌으면 '확정'과 기준 2줄만, 아니면 남은 것과 다음 질문(번호, 3개 이하)을 답에 적어. 커밋.
실무자 답: <메신저 답 붙여 넣기>
```

- 사람이 정한 값은 끝에 `우리 결정: <무엇 · 고른 값 · 근거>` 한 줄 · 질문을 그만하려면 끝에 `질문은 더 만들지 말고 남은 것은 정해서 DECISIONS 에`
