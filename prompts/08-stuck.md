# 08 막힐 때 · 같은 오류가 두 번 나면

```
목표: <오류·증상>의 원인을 찾아. 맥락: 명령 <명령>, 오류 원문 <붙여 넣기>, 해 본 것 <내용>.
제약: 고치기 전에 원인 가설 2개와 확인할 명령부터. 확인 뒤 가장 작은 수정만. 원인 한 줄을 STATUS '막힌 것'에. 파일 고침은 apply_patch, 확인 명령은 혼자 한 명령으로.
완료: 같은 명령이 성공하면 DECISIONS(과제가 AI 협업 기록 문서를 주면 거기)에 발견 · AI 진단 · 받아들임/고침/버림 · 확인 숫자 한 줄을 남기고 커밋. 같은 방법이 두 번 실패하면 멈추고 물어.
```
